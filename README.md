# Compra Certa Online

Projeto Next.js com Supabase para vitrine de afiliados. Veja `LEIA-ME-PRIMEIRO.txt` antes de configurar.

## Rodar localmente
1. Instale Node.js.
2. Copie `.env.example` para `.env.local` e preencha as variáveis.
3. Execute `npm install` e `npm run dev`.
4. Configure o banco usando `supabase/schema.sql`.

O site não está publicado por este pacote.
